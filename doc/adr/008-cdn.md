# ADR-008: The Embed Script Is Loaded from jsDelivr, at a Pinned Version

## Status

Accepted

## Context

Documentation sites are static, and often hosted where adding files outside the generator's output is awkward (GitHub Pages, Read the Docs). jsDelivr serves every version of `@smarter.sh/ui-chat`, with the `embed/` files that `embed.js` loads from beside itself.

## Decision

- Every package loads `https://cdn.jsdelivr.net/npm/@smarter.sh/ui-chat@<version>/dist/embed.js`, where `<version>` defaults to the exact version that this release is tested with.
- That version is written once, in the repository's `embed.json`, and copied into each package's source by `make embed-version V=x.y.z`. A test fails if a package's copy differs.
- A `version` option overrides it (e.g. `0.9` to follow patches), and a `src` option replaces the url, for sites that host `embed.js` and `embed/` themselves.

## Consequences

- **Positive:**
  - No files to copy into the site; what runs is what was tested.
- **Negative:**
  - Visitors' browsers download the script from jsDelivr, unless `src` is set.
